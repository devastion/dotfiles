# dotfiles

Personal dotfiles managed by `chezmoi`.

## 🚀 Quick Start

```bash
curl -fsSL https://raw.githubusercontent.com/devastion/dotfiles/refs/heads/main/install.sh | bash
```

```bash
curl -fsSL https://raw.githubusercontent.com/devastion/dotfiles/refs/heads/main/install.sh | bash -s -- --dry-run
```
